# 용인·동탄 IB TAB 안내 카운트

SA에게는 카운트 화면만 공유합니다. 숫자는 Google 시트 없이, 퇴근 때 복사한 한 줄을 Teams로 받아 이 컴퓨터 관리 HTML에 붙여 넣어 취합합니다.

Chrome 또는 Edge로 엽니다. OneDrive·Teams 미리보기는 쓰지 않습니다.

- SA 카운트 바로 열기: 상위 폴더의 `TAB_안내_SA카운트.html`
- GitHub 업로드용 카운트: 이 폴더의 `index.html` (내용은 위 파일과 동일)
- 관리 (올리지 않음): 상위 폴더의 `TAB_안내_SA카운트_관리.html`

## 역할

- 카운트: 센터 → 본인 이름 → 수락·거절·재연락·부재중 탭. 퇴근 전 오늘 숫자 복사.
- 관리: 인원·센터 편집, Teams 줄 붙여넣기, 센터별 정산, 주간 그래프, 보고문 복사.

기본 센터는 용인·동탄입니다. 용인 인원은 이영주·이현섭·나정주, 동탄 인원은 이한빈·이상택·박찬병·우용건·변제철입니다.

## 공유할 때

링크만 보냅니다.

https://hellgods1-source.github.io/tab-sa-count/?v=20261008

```
TAB 안내 카운트 (링크만 열기)
https://hellgods1-source.github.io/tab-sa-count/?v=20261008
센터 → 본인 이름 → 수락/거절/재연락/부재중
퇴근 전 「오늘 숫자 복사」를 이 방에 붙여 주세요.
```

하지 말 것: OneDrive HTML 미리보기, Teams 내장 뷰어. 구글 시트는 쓰지 않습니다.

## 담당자 (매일)

1. 위 링크를 Chrome/Safari로 엽니다.
2. 센터(용인/동탄)를 고른 뒤 본인 이름만 고릅니다.
3. 통화 직후 수락 / 거절 / 재연락 / 부재중을 탭합니다.
4. 퇴근 전 「오늘 숫자 복사」를 눌러 Teams에 붙여 넣습니다.

탭 숫자는 그 폰에만 있습니다. 취합은 복사한 줄이 관리 화면에 들어온 때입니다.

## 이 PC에서 취합

1. `TAB_안내_SA카운트_관리.html`을 Chrome/Edge로 엽니다.
2. 정산·보고 상단 Teams 취합에 받은 줄을 붙여 넣고 반영합니다. 여러 줄 가능합니다.
3. 보고문·당일 합계 복사, 주간 그래프는 기존과 같습니다.

인원을 바꾸면 관리 화면에서 고칩니다. 카운트 화면에 새 이름이 보이게 하려면 이 폴더 `index.html` 기본 명단을 맞춘 뒤 Pages를 다시 올립니다.

## GitHub Pages

이 폴더만 공개 저장소로 올립니다. 상위 `매니저 업무` 폴더와 `TAB_안내_SA카운트_관리.html`은 올리지 마세요.
